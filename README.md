# RUNLOG

Локальный спортивный дневник с распознаванием тренировок и агентом для анализа истории.

![Интерфейс на вымышленных данных](docs/overview.jpg)

## Возможности

- Добавление тренировки по скриншоту, тексту или вручную.
- Проверка распознанных показателей перед сохранением.
- История в SQLite, недельная дистанция и средний темп бега.
- Вопросы к истории с журналом вызовов инструментов.
- Фото формы по датам с необязательными измерениями веса.
- Проверка дат, диапазонов значений и повторных записей.
- Экспорт записей в JSON.

## Запуск

Требуются **Node.js 24+** и **Codex CLI** с действующей авторизацией. Внешних npm-зависимостей нет.

```sh
codex login status
npm start
```

Открыть http://127.0.0.1:8787. Остановка — `Ctrl+C`.

Ручное ведение дневника и просмотр фотографий работают без подключения модели. Для распознавания и вопросов к истории нужен доступный Codex.

### Настройки

| Переменная          | Назначение                      | По умолчанию    |
| ------------------- | ------------------------------- | --------------- |
| `SPORT_PORT`        | Порт локального HTTP-сервера    | `8787`          |
| `SPORT_CODEX_BIN`   | Путь к исполняемому файлу Codex | `codex` из PATH |
| `SPORT_CODEX_MODEL` | Доступная в аккаунте модель     | Выбор Codex CLI |

## Архитектура

```text
Браузер → HTTP-сервер → цикл агента → Codex CLI → JSON-действие
                            ↑                         ↓
                    результат инструмента ← диспетчер инструментов
                                                      ↓
                                           ответ или черновик
                                                      ↓
                                    подтверждение пользователя → SQLite
```

Модель выбирает следующее действие с учётом запроса и результатов предыдущих шагов. Сервер выполняет только поддерживаемые действия:

| Действие          | Назначение                                   |
| ----------------- | -------------------------------------------- |
| `list_workouts`   | Прочитать последние записи                   |
| `get_progress`    | Рассчитать показатели по сохранённой истории |
| `propose_workout` | Подготовить черновик тренировки              |
| `ask_user`        | Запросить уточнение                          |
| `respond`         | Завершить цикл ответом                       |

Агент ограничен четырьмя шагами. Повтор уже выполненного инструмента прерывает цикл. Сохранение и удаление записей выполняются отдельными действиями пользователя, а не по решению модели.

Расчёты выполняет код: средний темп равен суммарному времени, делённому на суммарную дистанцию пробежек с обоими показателями. Ходьба и другие виды активности в статистику бега не включаются.

### Файлы

```text
agent.mjs          инструкции, схема ответа и цикл агента
core.mjs           валидация и расчёты
store.mjs          SQLite и хранение изображений
server.mjs         HTTP API и запуск приложения
public/            интерфейс без фреймворков
tests/             автоматические проверки и синтетический снимок
```

## Данные и доступ

Записи и изображения хранятся в `data/`, которая исключена из Git. Сервер слушает только `127.0.0.1`; изменяющие запросы требуют токен текущего запуска и проверку Origin.

Для распознавания снимок тренировки и текст передаются облачной модели через Codex CLI. Вопросы к истории передают модели результаты вызванных инструментов. **Фото формы модель не обрабатывает:** они сохраняются локально для сравнения по датам.

Приложение использует существующую авторизацию Codex и не хранит её копию. Пользовательская конфигурация Codex не загружается, чтобы не подключать посторонние MCP-серверы. Процесс запускается с read-only sandbox и структурированным ответом. Инструкция запрещает встроенные инструменты CLI; это не равнозначно полной изоляции чтения файлов на уровне ОС.

JSON-экспорт содержит записи, но не сами изображения. Для резервной копии фотографий нужно сохранить папку `data/`.

## Проверки

```sh
npm test
```

Тесты проверяют неверные даты и числа, взвешенный темп, дубли, сохранение истории после перезапуска, работу с фотографиями, выбор инструментов, остановку повторов и HTTP-проверки. Авторизация и реальные вызовы модели для автоматических тестов не требуются.

Для ручной проверки распознавания есть `tests/fixtures/workout.png` — вымышленная тренировка. В интерфейсе также доступен демонстрационный набор, который не записывается в личную историю.

## Ограничения

Первая версия предназначена для одного пользователя на своём компьютере. Нет синхронизации с часами, импорта GPX/FIT, MCP-сервера и тренировочных рекомендаций. Ошибочную запись можно удалить и добавить заново. Изменение темпа или дистанции само по себе не доказывает улучшение физической формы.
