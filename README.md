# RUNLOG

Личный дневник бега с записью через Telegram, локальным распознаванием фото и проверяемыми сводками. Тренировки и изображения хранятся в SQLite и каталоге данных на Mac.

## Запуск

Node.js 24+, macOS. Для локального OCR нужны Apple Command Line Tools; для ИИ — установленный и авторизованный Codex CLI.

```sh
npm ci --ignore-scripts
cp .env.example .env
npm start
```

Открой [127.0.0.1:8787](http://127.0.0.1:8787). В разделе **Подключения** введи токен своего бота от [BotFather](https://t.me/BotFather), перейди по появившейся ссылке и нажми «Начать» в Telegram. Токен хранится только в локальном `.env`; одноразовая ссылка закрепляет доступ за твоим аккаунтом. Дневник и бот запускаются одной командой.

Mac должен оставаться включённым и подключённым к интернету. Закрытая крышка или сон останавливают доступ к боту до пробуждения. Публичный сервер и проброс портов не нужны.

## Запись с телефона

| Действие | Команда |
|---|---|
| Начать таймер | `/run` |
| Пауза / продолжение | `/pause` / `/resume` |
| Завершить | `/finish`, затем отправить дистанцию числом |
| Проверить таймер | `/runstatus` |
| Ввести готовый результат | `/log 3,2 24:30` — километры и минуты:секунды |
| Время больше часа | `/log 10 1:05:00` |
| Сводка / история / сравнение | `/summary`, `/history`, `/compare` |
| Шаги / экспорт | `/activity`, `/export` |
| Удалить незавершённый таймер | `/discardrun` |

Таймер переживает перезапуск приложения, исключает паузы и использует время отправки команд Telegram. GPS-дистанцию он не измеряет. После финиша можно отправить `/nodistance`, чтобы сохранить только время. Показатели записываются после подтверждения.

Фото дорожки → выбрать «Тренировка / дорожка» → проверить черновик → сохранить. На Mac сначала используется Apple Vision: снимок остаётся на компьютере. Если однозначных показателей нет, выполняется распознавание через Codex. На веб-странице эти способы разделены кнопками «Распознать на Mac» и «Распознать с ИИ».

Локальный OCR заполняет только показатели с явными подписями и единицами. Неоднозначные значения остаются пустыми. Темп не превращается в длительность; вес и физическая форма по фото тела не определяются. Для фото формы есть отдельный раздел.

## Apple Health

iPhone → «Команды» → `iCloud Drive / Shortcuts / runlog-health.json` → RUNLOG. Оба стандартных расположения Shortcuts на Mac проверяются каждые 15 секунд. Файл можно импортировать вручную через «Импорт XML / JSON».

**Ограничение:** на проверяемом iPhone команда с чтением Health вылетает даже с лимитом одного образца. Исправление на устройстве пока не подтверждено. Запись пробежек, OCR и сводки от Health не зависят.

Новая [Health Sync v2](shortcuts/RUNLOG%20Health%20Sync.shortcut) читает только сегодняшний день, передаёт столбцы пакетно, не перебирает каждый образец и ограничивает объём запроса. Экспорт при достижении лимита отклоняется как потенциально неполный. Исходник — `scripts/build-shortcut.py`; команда подписана Apple, но подписание не является проверкой выполнения на iPhone.

Повторный импорт обновляет снимок дня, не прибавляет его заново. Пустой экспорт не считается нулём. Разные источники не складываются. Повседневная дистанция не считается дистанцией пробежки; первый импорт нужно сверить со «Здоровьем».

## Агент и проверка результатов

Вход: запрос или фото. Модель выбирает инструмент: `list_workouts`, `get_progress`, `get_activity`, `compare_workouts` или `propose_workout`. Приложение выполняет инструмент и возвращает результат. Память — сохранённые записи SQLite; цикл ограничен четырьмя шагами.

Выход: черновик для подтверждения или отчёт с исходными записями. Суммы, взвешенный темп и сравнения считает код. Текст модели не подменяет проверенные цифры. Быстрые кнопки сводок и команды Telegram работают без модели. При ограничении запросов Codex приложение сообщает причину вместо ожидания повторных попыток.

## Настройки и данные

| Переменная | Назначение |
|---|---|
| `RUNLOG_DATA_DIR` | Каталог SQLite и изображений; по умолчанию `data/` |
| `RUNLOG_SYNC_FILE` | Необязательный путь к файлу Health |
| `RUNLOG_HEALTH_SOURCE` | Точное имя источника при неоднозначности |
| `SPORT_CODEX_BIN`, `SPORT_CODEX_MODEL` | Путь к Codex и необязательная модель |
| `SPORT_TIMEZONE`, `SPORT_PORT` | Часовой пояс и локальный порт |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID` | Записываются при подключении бота |

`.env`, база, изображения и исполняемый файл OCR исключены из Git. Для полной резервной копии сохрани каталог данных при остановленном RUNLOG; JSON-экспорт не содержит файлов изображений.

HTTP-сервер слушает только `127.0.0.1`. Изменения требуют токен запуска и допустимый Origin. Другие Telegram-аккаунты и групповые чаты игнорируются. Codex вызывается без пользовательской конфигурации, в read-only sandbox; это не полная изоляция чтения файлов на уровне ОС.

## Проверки

```sh
npm test
```

Тесты используют отдельные временные дневники. Проверяются расчёты и единицы, повторный импорт, подтверждение записей, привязка владельца, таймер после перезапуска и задержки доставки команд, неполный экспорт, HTTP-доступ и защита отчётов от выдуманных чисел.
