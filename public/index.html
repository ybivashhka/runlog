    ИСТОЧНИКИ ДАННЫХ

    Подключения.

    iPhone → iCloud Drive → RUNLOG.

    Apple Health через «Команды»

    1. Передай RUNLOG Health Sync.shortcut на iPhone, например через AirDrop, и добавь в «Команды».
    2. Запусти на iPhone. Разреши чтение шагов и дистанции ходьбы и бега. В действии «Сохранить файл» проверь папку iCloud Drive / Shortcuts, имя runlog-health.json и замену существующего файла.
    3. В «Команды → Автоматизация» добавь запуск RUNLOG Health Sync при открытии Telegram. Выбери немедленное выполнение. Первый запуск выполни вручную на разблокированном iPhone.
    4. Оставь RUNLOG запущенным на Mac. После появления файла в iCloud данные обновятся в течение 15 секунд. Сверь первый результат с «Здоровьем».

    На Mac и iPhone нужен один iCloud Drive. Когда Mac выключен, импорт возобновится при запуске RUNLOG. Команда читает последние 8 суток; самый ранний неполный день исключается. Отсутствие образцов не считается нулём шагов.

    Telegram

    Для подключения запусти npm run setup:telegram на Mac, затем npm run bot. Токен вводится локально.

    Фото дорожки → распознанный черновик → подтверждение. /activity — шаги, /summary — пробежки, /history — история.
